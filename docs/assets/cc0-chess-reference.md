# CC0 chess-piece reference

The knight and bishop silhouettes in `web/renderer/PieceGeometryFactory.js` were redesigned after reviewing the **LowPoly Chess Set** by Nailfighter.

- Source: https://nailfighter.itch.io/lowpoly-chess-set
- License: Creative Commons Zero v1.0 Universal (CC0-1.0)
- Permitted uses stated by the author: personal, educational and commercial work

The repository does not redistribute the original `.fbx` or `.blend` files. The runtime pieces remain optimized procedural Three.js geometry so the browser build stays small, deterministic, offline-capable and easy to recolor for both sides.
